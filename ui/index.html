How the Ceiling Hook Works

100% On-Chain · Token-2022 Transfer Hook
Street Sold Range Allowed Chips Max Wallet Min Net Tx
S1 Preflop 0 → 50M 25k / 50k 200k 1,000
S2 Flop 50M → 150M 25k / 50k 1M 2,000
S3 Turn 150M → 375M 25k / 50k / 75k 4.5M 3,000
S4 River 375M → 775.4M 25k / 50k / 75k / 100k 20M (2%) 4,004 + tail
  • Fixed Chips Only: Every buy and sell must equal a 25,000-token multiple up to the active street max, or the hook reverts with InvalidBetSize.
  • Hard Wallet Ceiling: Post-trade wallet balance cannot exceed the street hold cap (max 20M = 2% on S4), or the hook reverts with ExceedsHold.
  • DEX-Only While Live: Direct wallet-to-wallet transfers revert with P2PBlocked.
  • Reversible Streets: Sells return tokens to the pool vault and can push the table back to an earlier street.
  • Uncapped Graduation: Reaching the migration threshold revokes the transfer hook in the same swap and migrates liquidity to Meteora DAMM v2 with no limits after.
